## Features

<CardGrid>
	<Card title="Live preview" icon="pencil">
		Headings, emphasis, inline code and links render in place. Their syntax shows only where the
		cursor is.
	</Card>
	<Card title="Rich blocks" icon="puzzle">
		Images, clickable task checkboxes, code blocks with copy, and GFM tables, all as Svelte
		components.
	</Card>
	<Card title="Svelte 5 native" icon="seti:svelte">
		`bind:value`, runes and snippets. Renders on the server in SvelteKit without touching the
		DOM.
	</Card>
	<Card title="Themeable" icon="seti:css">
		Every colour, font and size is a CSS variable, with light and dark modes built in.
	</Card>
</CardGrid>
