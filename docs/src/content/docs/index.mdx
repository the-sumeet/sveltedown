## Features

<CardGrid>
	<Card title="Rich text editing" icon="pencil">
		Headings, lists, check lists, quotes, links, images and tables, edited like a document and
		stored as Markdown.
	</Card>
	<Card title="Code, source and diff" icon="seti:code-search">
		CodeMirror code blocks with syntax highlighting, plus a Markdown source view and a diff
		against an earlier version.
	</Card>
	<Card title="Extensible" icon="puzzle">
		Plugins, a composable toolbar, directives, admonitions, front-matter, MDX JSX components,
		and your own Svelte editors for custom nodes.
	</Card>
	<Card title="Svelte 5 native" icon="seti:svelte">
		`bind:markdown`, snippets and components throughout. Renders on the server in SvelteKit.
	</Card>
</CardGrid>

sveltedown is a port of [MDXEditor](https://mdxeditor.dev) to Svelte. Its plugins, options and
reactive state keep MDXEditor's names, so its documentation mostly applies too.
