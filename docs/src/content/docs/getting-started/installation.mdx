---
title: Installation
description: Install sveltedown and add its stylesheet.
---

```sh
npm install @the-sumeet/sveltedown
```

`svelte@^5.40` is a peer dependency. The editor is built on [Lexical](https://lexical.dev) and
uses [CodeMirror](https://codemirror.net) for code blocks and the source view; both are installed
with it.

## Styles

The editor imports its stylesheet itself, so most setups need nothing more. If your bundler drops
CSS imported from packages, import it once in your app:

```js
import '@the-sumeet/sveltedown/editor.css';
```

## Server rendering

The editor renders its container on the server and creates the Lexical editor in the browser, so
it works in SvelteKit pages without extra setup.
