## Rendered

Away from the cursor, a fenced block renders as one widget:

- a header with the language and a **Copy** button
- the code in a box that **scrolls sideways** instead of wrapping long lines, without moving the rest of the document

You can select and copy text straight from the rendered block, and scroll it, without leaving the rendered view.

## Editing

A plain click on the code opens the block for editing, with the cursor on the character you clicked. While editing:

- the fences and info string show as source
- lines still don't wrap; the editor scrolls sideways to follow the cursor
- **Home** and **End** (Cmd-Left/Right on macOS) go to the real start and end of the line

Inside a list or blockquote, the list indentation and `>` markers are not part of the code: they don't appear in the rendered block or in what Copy copies, and Home stops after them.

## Language and info string

The text after the opening fence is the info string. The **language** is its first word:

````md
```ts title="config.ts" {1,3}
````

Here the language is `ts`. The whole string is available as `info`, so a custom header can show a title. See [Custom snippets](../custom-snippets/#code-block-header).

## Customising

- Replace the header (language and Copy) with `codeHeaderSnippet`; see [Custom snippets](../custom-snippets/#code-block-header).
- Style the block with CSS variables and classes; see [Theming](../theming/#element-classes).
