import EditorDemo from '../../../components/demos/EditorDemo.svelte';

```ts
import { tablePlugin } from '@the-sumeet/sveltedown';

const plugins = [tablePlugin()];
```

Each cell is an editor of its own, so it can hold formatting, links, images and inline code. The
menus on the column and row edges insert and delete columns and rows, and set the alignment of a
column. Tab and Shift+Tab move between cells, and Enter and Shift+Enter move down and up.

`tablePlugin` takes the `mdast-util-gfm-table` options, `tableCellPadding` and `tablePipeAlign`,
which both default to `true`. HTML tables are not supported.
